Wie wahrscheinlich ist was?

Chance, dass das Szenario am Standort in den nächsten 30 Jahren mindestens einmal eintritt – aus amtlichen Daten und Messreihen, bei Kaiju und Aliens aus Modellrechnungen mit Fachliteratur. Rot = häufig (bis alle 30 Jahre), Orange = bis alle 300 Jahre, Grün = seltener.

Selbst starten – mit deinem Gebiet

Im vollen Werkzeug wählst du ein beliebiges Gebiet in Deutschland und stellst jedes Szenario selbst ein: Pegel, Regenmenge, Windrichtung, Erdbebenstärke, Größe des Monsters … Die Demo zeigt die Standard-Szenarien für ein Beispielgebiet.

git clone https://github.com/Jade-HS-Vibecoding-WPK/TERRA-Sim
cd TERRA-Sim
pip install -r requirements.txt
streamlit run app.py

TERRA-Sim ist ein Streamlit-Werkzeug (Python). GitHub Pages kann nur statische Seiten ausliefern – deshalb ist diese Demo vorberechnet, mit genau demselben Code und demselben 3D-Viewer.
